Signal Chamber style guide

A dark, centered landing page with a metal gate, blue aperture, and copper glyphs. The gate marks are decorative. They are not a tunnel address.

This guide uses the current StarTunnel landing-page styles. Open the representative screen.

Colors and surfaces

Use one graphite surface family. Blue marks the action and aperture. Copper marks the glyphs. Keep body text light on the dark background.

Page--color-paper
Raised surface--color-paper-raised
Divider--color-rule
Action--color-accent
Gate light--color-gate-blue
Glyph--color-gate-copper

Production tokens also define ink, muted text, focus, success, and error colors. Use the production variables, not copied color values.

Use Space Grotesk for headings and the StarTunnel wordmark, Inter for body and controls, JetBrains Mono for code, and Noto Sans Symbols for address glyphs. The logo uses the shared footless vector of 🜎 (U+1F70E, philosophers' sulfur) beside the wordmark at weight 700. Keep heading lines short and use the production text scale and line heights.

Spacing and layout

  • --page-gutter
    Responsive outer space.
  • --page-max
    Maximum page width.
  • --space-sm
    Gap between related controls.
  • --space-2xl
    Section separation.

Center the hero copy and gate. Keep the primary action in the first viewport. Use open sections and thin dividers; reserve raised surfaces for content that needs containment. Controls use a 6 px radius, a hairline border, and a minimum 2.75 rem height.

Navigation and controls

Connect your agent Follow the tutorial

Links navigate. Buttons change page state or submit forms. The live landing page provides agent prompts and guide links. Without JavaScript, visitors can read and select each prompt. Hover and pressed styles come from the production buttons. Keyboard focus uses the production focus ring.

When should the interface reveal more text?

Use a native disclosure for nearby supporting text. Keep the summary clear without a script.

Gate image and glyphs

The static ring image is decorative. The eight glyphs remain text over the image, in the approved order. Keep the gate square. The center uses the blue aperture surface.

Feedback and access

The static gate remains visible if motion is reduced, JavaScript is off, or WebGL is unavailable.

Example error: A page could not load. Try again.

Keep feedback in text, not only in color. Show loading and empty states only where a real workflow needs them. Give interactive controls names, a visible focus state, and a touch target of at least 2.75 rem. Do not use gate motion to complete a task. Reduced-motion settings stop optional animation.
